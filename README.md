# 生产力仪表盘 (Productivity Dashboard)

一个简洁实用的网页版生产力工具，集成**番茄钟**和**任务清单**，无需安装，打开即用。

## 功能特性

### 番茄钟
- 三种模式：专注 25 分钟 / 短休 5 分钟 / 长休 15 分钟
- 开始 / 暂停 / 重置
- 自动记录每日完成的番茄数量（本地存储）
- 倒计时结束时提醒

### 任务清单
- 添加、完成、删除任务
- 实时统计总数与已完成数
- 数据自动保存到浏览器本地存储

## 使用方法

直接用浏览器打开 `index.html` 即可使用，无需任何依赖或服务器。

## 技术栈

- 原生 HTML / CSS / JavaScript
- LocalStorage 数据持久化
- 响应式布局，支持移动端

## 文件结构

```
productivity-dashboard/
├── index.html   # 页面结构
├── style.css    # 样式
└── app.js       # 交互逻辑
```

## 自定义

修改 `index.html` 中 `data-minutes` 属性可调整各模式时长。
